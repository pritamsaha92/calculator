## About

This repository hosts simple calculator demos built as standalone HTML pages. The GitHub Actions workflow publishes the repository contents from the `test` branch to the `gh-pages` branch, making each page available via GitHub Pages.

## How to Use

1. Click any of the links above.
2. The page opens in a new browser tab.
3. To update the demos, push changes to the `test` branch.
